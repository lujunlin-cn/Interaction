## Design rule

Only promote a candidate when it has repeated reasoning, a stable input/output contract, reusable scope, an observable result, and an independent evaluation. Context projection, prompt formatting, StateManager, exact dedupe, ffmpeg and provider polling remain ordinary tools. This prevents a registry full of renamed helper functions.

## Highest-value next evaluations

1. Add stage and turn/epoch IDs to intent and choice spans so one player action has one causal Skill chain.
2. Count every considered mechanic trigger, including disabled/rejected/not-applicable, then label precision/recall on held-out turns.
3. Enforce fail-closed adapter contracts even when an adapter is called outside arbitration; direct calls must reject missing targets and unknown actions/stages.
4. Add semantic duplicate labels to Jev Top-K replay before considering MMR or a new diversity model.
5. Keep Evidence-Bound Knowledge and Narrative Continuity Critic as advisory research until false-rejection and latency budgets are measured.
